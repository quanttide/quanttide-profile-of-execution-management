# QtCloud（量潮云）

## 定位

云业务——产品工厂：基础设施优先，批量上线产品（三朵云 + 业务云），每个基建降低下一个产品成本。

## 重点

- **基础设施优先**：文档中心、工具库、复盘框架——每个基建降低下一个产品成本
- **批量上线**：三朵云（支付/身份/议事）+ 业务云（课程/财务/人力/实训账本）——一周多产品是常态
- **阻塞即优先**：部署链路上的卡点优先清除
