# 量潮课堂实训基地账本配套审批

## 需求

量潮课堂实训基地账本记录实训执行情况，业务系统需要可信记录。当前账本记录缺乏审批依据，业务系统无法确认记录可信，需要补充配套审批。

## 目标

以审批为事实源，为业务系统提供可信记录：账本记录 → 配套审批 → 对账一致。

验收标准：
- [ ] 决策明确审批为事实源
- [ ] 产品经理制作审批单，覆盖全部账本记录
- [ ] 课程助教完成验收，审批记录可追溯
- [ ] 全栈工程师对账一致，业务系统采用审批结果作为可信记录
- [ ] 复盘输出改进项

## 分工

按 RACI 责任矩阵划分（R=执行负责，A=问责，C=咨询，I=知会）：

- **课程主管**：授权型上级——只做决策并看结果，不直接参与事务，责任随授权下放；决策 R，计划/执行/评审 I
- **产品经理**：负责人——整体问责到此（A）；计划 R、执行 R，决策 C、评审 C
- **课程助教**：复核/评审人——与产品经理共同承担责任；评审 R，决策/计划/执行 C
- **全栈工程师**：不在本任务内，仅被知会（I）——对账为业务系统侧后续工作

### 1. 决策

课程主管决定做账本配套审批：为业务系统提供可信记录。

### 2. 计划

产品经理负责制定配套审批方案：以审批为事实源，账本记录与业务系统记录均以审批结果为准。

### 3. 执行

产品经理负责制作：设计审批事项与审批单，覆盖账本记录。

实训执行并登记账本记录：账本如实记录实训执行情况，作为审批验收对象。

### 4. 评审

课程助教负责验收：核对账本记录与实训实际执行，给出审批结果。

### 5. 复盘

回顾审批全流程，改进审批模板与规则，沉淀为业务系统可信记录基线。
